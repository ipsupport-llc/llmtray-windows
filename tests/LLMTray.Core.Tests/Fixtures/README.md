# Test fixtures

Documents written by other programs, to test our readers against real
producers. Each was generated for these tests and holds no outside content.

- `textutil.doc`: Word 97-2003, `textutil -convert doc` (macOS) from a
  three-line text file (English, Russian, "café").
- `xlwt.xls`: Excel 97-2003 (BIFF8), written by the Python `xlwt` package:
  sheets "Prices" (strings, numbers, a formula with no saved result, a
  boolean), "Empty" and "Second".
